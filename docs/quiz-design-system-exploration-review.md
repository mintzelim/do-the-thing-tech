# Quiz Design-System Exploration Review

The approval-only quiz exploration was visually reviewed at desktop width on 18 August 2026. All three directions consistently use the warm-gray page canvas, Inter-led title and reading hierarchy, VT323 contextual labels, warm-white panel surfaces, blue-gray outlines, light shadows, and the canonical lavender mascot.

**Option 01 · Focus Field** most directly matches the existing homepage task-tool language. Its open two-column hero, signal panel, visible question progress, and large answer rows form a coherent product journey without a dark full-screen game frame. **Option 02 · Pattern Field Guide** is clearly more editorial and resource-led. **Option 03 · Gentle Questline** retains measured playfulness through checkpoint markers while avoiding the current sky-scene, emoji, all-pixel-text, and heavy black-border vocabulary.

The exploration explicitly preserves the current ten-question scoring and result mechanics. Any selected implementation should also add a clear non-diagnostic self-reflection boundary before retaining or reframing the current “ADHD type” presentation.
