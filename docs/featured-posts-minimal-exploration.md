# Featured Posts · Minimal Exploration

This approval-only exploration keeps **Learning Paths** as the homepage’s primary navigation and proposes three quieter alternatives for the Featured Posts section.

| Option | Direction | Best use |
|---|---|---|
| **01 · Quiet List** | Five compact rows with title, optional note, and arrow. | The calmest, most scan-friendly continuation. |
| **02 · Editorial Shelf** | A low-contrast editorial grid with one gentle lead item. | A little more library character without card-heavy emphasis. |
| **03 · One More Thing** | One optional lead guide plus four background links. | One article is timely enough to elevate, while Learning Paths remain primary. |

All directions retain the existing five post destinations and the **View all posts** exit. They use a single warm-white surface, quiet outlines, Inter for reading, VT323 only for micro-labels, and no images or nested card treatments.

## Selected implementation

**Option 03 · One More Thing** was selected and is now applied to the live homepage. It presents one optional lead guide and four compact secondary links, allowing Learning Paths to remain the primary homepage starting point. Options 01 and 02 remain reference-only.

## Visual review record

Desktop review confirmed that all three directions remain visually quieter than the preceding Learning Paths: Option 01 uses only a single list rail, Option 02 uses a no-shadow editorial grid inside one surface, and Option 03 limits emphasis to one optional lead item plus a compact reading stack. All three retain the warm-white panel, calm blue-gray outline, Inter reading hierarchy, and one low-emphasis library exit.
