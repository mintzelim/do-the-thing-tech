NON-NEGOTIABLE BEHAVIOUR

Friendly, not fake input.

  • The real textarea stays blank: examples never prefill, submit, or overwrite someone’s words.
  • Focus wins: the prompt overlay immediately hides when the field is focused or contains text.
  • Motion is optional: reduced-motion visitors see the first example, no movement, and a solid caret.
  • Access is preserved: the visual overlay is hidden from assistive technology; the existing “Task or brain dump” label remains the field’s accessible name.
