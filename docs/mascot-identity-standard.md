# DoTheThing Mascot Identity Standard

The supplied audience and editorial illustrations define the **canonical DoTheThing mascot**. All new visual uses must preserve this identity rather than introducing a lookalike.

| Identity anchor | Required treatment |
| --- | --- |
| Silhouette | A compact, upright rounded rectangular lavender creature with a clear blocky pixel-art body. It is not a human character, animal, or generic blob. |
| Face | Two small, evenly spaced navy square eyes; use the same minimal, friendly expression language as the supplied examples. |
| Form and depth | Lavender front face, deep navy-purple side/shadow planes, dark navy pixel outline, small block feet and arms where visible. |
| Surface detail | Small upper-left highlight only; retain restrained 8-bit pixel shading rather than smooth vector gradients or new facial features. |
| Palette | Lavender body with navy outlines and shadows; retain the existing warm, calm DoTheThing pixel-art palette. |
| Usage rule | Reuse an approved asset or generate only from these explicit anchors. Do not redraw, restyle, recolor, humanize, or alter the character’s proportions. |

The final landing CTA uses the existing remote-worker mascot asset because it is an approved transparent production asset that preserves this exact silhouette and pixel treatment. The surrounding speech bubble may vary by context, but the creature itself must not.
