# Directory Footer Validation

The selected **Option 01 · The Directory** footer is implemented as four labelled groups: **Product**, **Learn**, **Trust**, and **Explore**. The live article-page check confirms that all groups render inside one warm-white 14px panel with a separate pale-indigo utility base.

The footer exposes the newly created public GEO routes, including **How it works**, **Editorial standards**, **Compare with Goblin.tools**, and **Media information**, alongside the established product, blog, quiz, legal, contact, and social routes. Its grid remains readable without nested bordered surfaces; the responsive stylesheet changes the four groups to two columns before the smallest screens.
