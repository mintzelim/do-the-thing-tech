# Task Widget New Sticker Reference Notes

The supplied reference uses a compact warm-yellow rectangular sticker, rotated slightly counter-clockwise at approximately eight degrees. Its readability comes from a **2px dark outline**, a **2px dark offset shadow** down and right, bold dark sans-serif “NEW!” lettering, and intentional overlap with the surrounding white panel. The sticker is a visual signal, not a button or control.

For DoTheThing, the sticker options should make the task textarea’s editable nature obvious without blocking the field label, placeholder, focus state, or keyboard interaction. Each option stays selection-only in the visual design-system HTML until the user selects a live treatment.
