# Quiz Visual Refinement Review

## Current audit

The seven pre-quiz mascot image elements all load successfully at 1920 × 1920 and render at 132 × 94 pixels. At that small shared canvas size, the actual mascot scenes sit too quietly within the oversized transparent artwork bounds; they do not provide enough visual recognition in the current dense desktop seven-card row.

The next approval-only refinement will test a clearer composition that gives the mascot scenes a deliberate framed image rail, preserves the existing friendly pattern names and supporting sentences verbatim, and keeps the wide desktop comparison-friendly layout from becoming a stack of nested card surfaces.

## Constraint

No live layout, scoring, pattern copy, result copy, attribution, or clinical boundary is changed during the approval-only exploration.

## Approval-only direction review

All three directions render the seven verified true-alpha scenes clearly at a useful size.

| Direction | Visual finding | Best use |
|---|---|---|
| Option 01 · Scene Stack | A four-up first row and breathing room around the final three cards lets every mascot scene read immediately. | Recommended default for the existing “Meet the Patterns” section. |

The preview is approval-only. The live quiz remains unchanged while a direction is selected.
