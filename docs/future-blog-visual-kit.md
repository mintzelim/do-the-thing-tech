# Future Blog Visual Kit

This kit provides three reusable, no-text editorial illustrations for future DoTheThing articles. Each scene must use the **canonical lavender rounded-rectangle mascot** with square navy eyes, a dark navy pixel outline and side planes, and restrained lavender highlights. Never substitute a person, animal, blob character, or a different mascot design.

The files are published through the public GitHub release **`dothething-assets-v1`**. Use the release URL matching the file name below; do not use a Manus storage URL in blog Markdown or application code.

| File | Best-fit article purpose | Suggested accessible alternative |
| --- | --- | --- |
| `blog-kit-first-step-trail.png` | Task initiation, breaking down work, procrastination, or overwhelm | Canonical purple mascot stepping between tiny task cards on a gentle path. |
| `blog-kit-focus-lantern.png` | Focus, attention, decision-making, distraction, or executive function | Canonical purple mascot holding a lantern beside one clear path through attention clouds. |
| `blog-kit-reset-garden.png` | Burnout, rest, sustainable productivity, emotional regulation, or routines | Canonical purple mascot watering three small plants in a calm reset scene. |

## Publishing rule

After adding a new kit file to the GitHub release, reference it in content with this pattern:

```text
https://github.com/mintzelim/do-the-thing-tech/releases/download/dothething-assets-v1/<file-name>
```

Use each scene only when its visual meaning matches the article. Do not repeat a scene within the same article, and create a new canonical-mascot scene rather than forcing an unrelated existing image into a future post.

## Pre-publication visual check

The First-Step Trail and Focus Lantern scenes were checked before GitHub release publishing. Both are 2560 × 1440 no-text pixel-art scenes with one lavender, rectangular, square-eyed mascot, navy outline treatment, and no human or animal character.

The Reset Garden scene passed the same check and was published alongside the other two files. All three release URLs returned HTTP 200 on 24 August 2026.
