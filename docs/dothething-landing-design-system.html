Actions and focus

Purposeful response

Hover feedback uses a two-pixel lift and an indigo darkening. This acknowledges the action without disturbing page layout.

Motion boundaries

Use only transform, opacity, and color-related motion. Avoid looping decoration, parallax, or animated width and height changes.

140ms transform 160ms color

Reduced-motion contract: when a visitor requests reduced motion, transitions and animations reduce to 0.01ms, animation iterations are limited, and scrolling returns to the browser default.

Alternate layout patterns

Use proportion, alignment, and intentional row balancing to help authority and resource pages breathe. Each pattern retains the same warm-white surface, radius, outline, readable Inter copy, and restrained interaction language.

Editorial split

Use a wide text-and-mascot composition, alternating the illustration side between sections. The reset comes from proportion, not a new color.

Wide editorial panel

A concise asymmetric header followed by an optional paced card grid makes product differentiation or a decisive call to action feel distinct without a second surface.

Canvas card field

Centered row

Mobile stack
